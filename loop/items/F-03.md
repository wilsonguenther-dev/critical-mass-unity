## Behaviour notes

- **Heights (U-003).** `Height01` is the Sim-owned height of each cell in world units: island `h` (0, 0.75 central,
  1.5 shrine), bridges lerp between endpoint islands, every other cell 0. No Phase 0 rule reads it; F-08b draws it.
  The browser comment "the sim ignores it" stays true for the base rules.
- `inRingGap` uses `Math.round(a / 90)`: port with `JsMath.Round` (an angle of exactly 45 rounds up in JS).
- `buildDecorations` mirrors with `(-d.ramp.dx || 0)` to avoid `-0`; C# `int` has no `-0`, port as `-d.Ramp.Dx`.
- `onRing` compares `ax === Math.floor(Math.sqrt(r2 - az * az)) + 0.5` exactly: keep the exact `==` on doubles
  (`Math.Sqrt` is correctly rounded in both runtimes).
- `cellAt` and `worldToCell` floor with `JsMath.FloorToInt` so a NaN point is out of bounds.
- `cells.fill`, `hgt.fill` -> `Array.Fill`.
