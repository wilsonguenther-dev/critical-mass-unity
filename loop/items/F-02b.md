## Behaviour notes

- The kaiju `Threat` array has length `ActorCapacity`; every per-actor array is allocated at `ActorCapacity` and reused by
  `ResetWorld` (the test checks reference equality: `Assert.AreSame`).
- `buildRoster` largest-remainder: port the loop and its tie-break (`>` versus `>=`) as written; `Math.floor` ->
  `JsMath.FloorToInt`.
- `CreateWorld` copies `map.cells` (`MapDef.WithCells((byte[])map.Cells.Clone())`) so breaking walls never edits the shared map.
- Seed: `Rng.CreateRng(unchecked((uint)opts.Seed))`.
- `spawnPoint` uses `slot % 3` and `teamSlot` uses `ActorCount >> 1`: non-negative ints, so C# `%` and `>>` give the
  JS values. `pushEvent` writes slot `EventHead % EventCapacity` then increments `EventHead` (int; 512 * 2^22 events
  before overflow, far beyond a match).
- `buildRoster` uses `CLASS_IDS.indexOf(humanClass)`: in C# `(int)humanClass` (enum order = `CLASS_IDS` order).
