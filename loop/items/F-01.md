## Behaviour notes

- **2x pace changes no tunable.** On `origin/cm/CM-66` the only config changes are `teamSize` 5 -> 16 and the new
  `defaultSpeed: 2` (placed after `teamSizeMax`). `DefaultSpeed` is the driver's time scale (sim ticks per wall second /
  30); `SimHz` stays 30, `MatchSeconds` stays 480 sim seconds (4:00 wall time at 2x), every rate stays per sim second.
  `CreateDefault()` and `CreateBrowser5v5()` therefore differ in exactly two fields: `TeamSize` (16 / 5) and
  `DefaultSpeed` (2 / 1). Every other value in the table is the browser main value, checked by script against
  `GAME_CONFIG` evaluated from game.config.ts on 09e0904 (167 leaves, 0 mismatches).

- `as const` / `satisfies` have no runtime meaning; C# fields are mutable so presets and `Clone()` work. No Sim code
  writes a config field.
- `toBeCloseTo(1, 6)` on the class-mix sum: tolerance `0.5e-6`.
- `Object.keys(c).sort()` in the five-classes test becomes: `Classes.Length == 5` and `ClassIds.All` lists the five
  enum values; the alphabetical sort has no C# counterpart and is not ported.
