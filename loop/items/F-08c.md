# F-08c Debug HUD and PlayMode smoke

Conventions apply. Namespaces `CriticalMass.Runtime.Hud`, `CriticalMass.Runtime.PlayTests`. Batch 4 compiles as one unit.

## Port from

No browser file is ported; the HUD shows Sim values the browser HUD shows (`matchClock`, hill seconds, allegiance,
instability), drawn as a debug overlay.

## Create

**`Runtime/Hud/DebugHud.cs`**: `public sealed class DebugHud : MonoBehaviour` with `public SimDriverBehaviour Driver;`
(set by `GameBootstrap`: `GetComponent<SimDriverBehaviour>()`). IMGUI `OnGUI`, refreshed text at 10 Hz (browser HUD
rate), one box at top-left, font size 14, lines in this order:

1. `mm:ss` of `Match.GetMatchClock(w).Remaining`, then `hatch in mm:ss` while not hatched, then `x{TimeScale}`;
2. `HILL {HillState}  azure {HillSeconds.Azure:F1}  crimson {HillSeconds.Crimson:F1}`;
3. `KAIJU {Kaiju.State}  hp {Hp:F0}/{MaxHp:F0}  allegiance {Allegiance.Azure:F0}/{Allegiance.Crimson:F0}  instability {Instability:F1}`;
4. `delivered biomass {Delivered[0].Biomass:F0}/{Delivered[1].Biomass:F0}`;
5. `PAUSED` while `HumanInputState.Paused`; `WINNER {Winner}` once `Phase == Ended`;
6. while `ScoreboardHeld`: one line per actor `id team cls kills/deaths aiState`.

Plus the last 6 events (type, a, b) read from the `Events` ring (`EventHead` back), refreshed at 10 Hz.

**`Runtime.PlayTests/CriticalMass.Runtime.PlayTests.asmdef`**: `name` `CriticalMass.Runtime.PlayTests`, `references`
`["CriticalMass.Sim", "CriticalMass.Runtime", "Unity.InputSystem", "UnityEngine.TestRunner"]` (Unity.InputSystem added by U-041 for the human-input test), `includePlatforms []`,
`precompiledReferences ["nunit.framework.dll"]`, `overrideReferences true`, `defineConstraints ["UNITY_INCLUDE_TESTS"]`,
`autoReferenced false`.

**`Runtime.PlayTests/SmokeTests.cs`** (**new, no vitest twin**): `public sealed class SmokeTests` with
`[UnityTest] public IEnumerator BootPlays16v16BotsFor60SimulatedSecondsWithZeroExceptions()`:
`SceneManager.LoadScene("Assets/_Game/Scenes/Boot.unity")`; `yield return null` twice; find the `SimDriverBehaviour`
(assert not null); set `HumanAutopilot = true`; assert `World.ActorCount == 32`; 60 times: `driver.StepTicks(30)` then
`yield return null` (renders between); assert `World.Tick == 1800` (plus the ticks run by `Update` during the yields,
so assert `>= 1800`); `LogAssert.NoUnexpectedReceived()`.

**`Runtime.PlayTests/HumanInputPlayTests.cs`** (U-041, **new, no vitest twin**; it drives F-08a's `HumanInputSource`
through the real project-wide actions, no Input System test framework, so `Packages/manifest.json` is untouched):
`public sealed class HumanInputPlayTests`. Shared setup per test: load Boot as `SmokeTests` does, `yield return null`
twice, find the `SimDriverBehaviour` (`HumanAutopilot = false`), `var kb = InputSystem.AddDevice<Keyboard>();`; teardown
`InputSystem.RemoveDevice(kb)`.

- `[UnityTest] HoldingWOnAVirtualKeyboardMovesActor0UpTheScreen`: record `x0 = World.X[0], z0 = World.Z[0]`;
  `InputSystem.QueueStateEvent(kb, new KeyboardState(Key.W)); InputSystem.Update();` then 30 times `yield return null`
  followed by `driver.StepTicks(1)`; assert `World.Actors[0].IsHuman`, and with `d = ((World.X[0] - x0), (World.Z[0] - z0))`
  assert `(-d.x - d.z) / Math.Sqrt(2) > 0.5` (screen up is sim (-1, -1) / sqrt 2, `SimSpaceTests`) and
  `Math.Abs(d.x - d.z) / Math.Sqrt(2) < 0.1` (no sideways drift).
- `[UnityTest] ReleasingWStopsActor0WithinTheBrakeTime`: hold W for 30 ticks as above, then
  `InputSystem.QueueStateEvent(kb, new KeyboardState()); InputSystem.Update();`, step
  `(int)Math.Ceiling(cfg.Movement.BrakeSeconds * cfg.SimHz) + 1` ticks with a `yield return null` before each, then
  assert `World.Vx[0] == 0 && World.Vz[0] == 0`.

**`tools/unity-playtest.sh`**: copy of `tools/unity-test.sh` with `-testPlatform PlayMode`, results
`Logs/playmode-results.xml`, log `Logs/playmode-tests.log`, and the summary prefix `unity-playtest:`.

## Numbers

HUD refresh 10 Hz; smoke: 32 actors, 1800 ticks (60 s at 30 Hz), 60 render frames.

## Behaviour notes

- `SceneManager.LoadScene` by path works in editor PlayMode because Boot.unity is in the build settings.
- The smoke test does not depend on wall time: `StepTicks` advances the Sim directly.
