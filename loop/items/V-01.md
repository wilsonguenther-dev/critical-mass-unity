# V-01 CM/Toon shader

Added by the architect on 2026-11-12 (U-041, panel deferred list: "a CM/Toon shader item in parallel with Phase 0, no
Sim dependency"). It waits on nothing, is built in batch 4's wave and lands with batch 4 as an uncoupled item (a red
drops it alone). This spec fixes ARCHITECTURE.md section 5's OPEN contract details; the values are the architect's
starting values, tuned later only through a U-### entry.

## Create

**`Assets/_Game/Art/Shaders/CMToon.shader`**: hand-written URP HLSL (not Shader Graph: a graph file is editor data a
builder cannot check without Unity), `Shader "CM/Toon"`, `Tags { "RenderPipeline" = "UniversalPipeline" "RenderType" = "Opaque" "Queue" = "Geometry" }`.

Properties, exactly these names, types and defaults (colours are the bible core palette, p05):

| Property | Declaration | Default |
| --- | --- | --- |
| `_BaseColor` | `Color` | Warm Cream `(0.968627, 0.941176, 0.898039, 1)` (#F7F0E5) |
| `_ShadeMultiplier` | `Range(0, 1)` | `0.62` |
| `_RampThreshold` | `Range(-1, 1)` | `0.0` |
| `_TeamColor` | `Color` | Azure Team `(0.086275, 0.780392, 0.850980, 1)` (#16C7D9) |
| `_OutlineColor` | `Color` | Void Navy `(0.094118, 0.137255, 0.231373, 1)` (#18233B) |
| `_OutlineWidth` | `Range(0, 0.1)` | `0.02` (object-space units) |
| `_RimWidth` | `Range(0, 1)` | `0.25` |
| `_RimStrength` | `Range(0, 1)` | `0.6` |

Team mask (fixes the OPEN choice): the **vertex colour red channel**. `r = 1` paints `_TeamColor` in place of
`_BaseColor`; `r = 0` keeps `_BaseColor`; values between lerp. Script-made Blender art writes it as a vertex colour
layer named `TeamMask` (U-043). No mask texture, no extra material slot.

Passes, in this order:

1. `Name "ForwardLit"`, `Tags { "LightMode" = "UniversalForward" }`, `Cull Back`, `ZWrite On`. Fragment, exactly:
   `albedo = lerp(_BaseColor.rgb, _TeamColor.rgb, input.color.r)`; `ndl = dot(normalize(normalWS), mainLight.direction)`;
   `lit = ndl > _RampThreshold ? albedo * mainLight.color : albedo * _ShadeMultiplier` (two flat bands; the main
   light's shadow attenuation multiplies `ndl` before the test); rim: `rim = 1 - saturate(dot(normalize(normalWS), normalize(viewDirWS)))`,
   `rimMask = rim > (1 - _RimWidth) ? 1 : 0`, `color = lerp(lit, _TeamColor.rgb, rimMask * _RimStrength)`; output
   `half4(color, 1)`. No additional lights, no ambient probe, no specular, no reflection probe, no fog.
2. `Name "Outline"`, `Tags { "LightMode" = "SRPDefaultUnlit" }`, `Cull Front`, `ZWrite On`: vertex
   `positionOS + normalOS * _OutlineWidth`, fragment `_OutlineColor` (the inverted hull).
3. `Name "ShadowCaster"`, `Tags { "LightMode" = "ShadowCaster" }`, using URP's `ShadowCasterPass.hlsl` include.

**`Assets/_Game/Art/Shaders/CMToonCommon.hlsl`**: the `CBUFFER_START(UnityPerMaterial)` block with the eight
properties above (SRP Batcher compatible: every pass includes it), and the shared vertex input struct
(`positionOS`, `normalOS`, `color`).

**`Assets/_Game/Runtime.Tests/ToonShaderTests.cs`** (namespace `CriticalMass.Runtime.Tests`, EditMode,
`public sealed class ToonShaderTests`, **new, no vitest twin**):

- U-008 forbids a second shader for characters, Kaiju and props; this is the one. Mechanics work keeps the placeholder
  material (F-07, F-08a); wiring `CM/Toon` into the views comes with the art items (A-02 onward).
- No `.mat` file is written (U-027). Materials on `CM/Toon` come from the art import step of the art items.
