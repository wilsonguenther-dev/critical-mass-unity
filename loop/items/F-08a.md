# F-08a Bootstrap, driver, placeholder views

Conventions apply. Namespaces `CriticalMass.Runtime.Game` and `CriticalMass.Runtime.View`. Batch 4 compiles as one unit
(the bootstrap creates F-08b and F-08c components). Runtime reads the Sim; it never writes Sim state except through
`MatchTick.Advance` and `HumanInputState.Fill`.

## Port from

`src/game/SimDriver.tsx` (69 lines: accumulator, per-tick order, interpolation alpha). Per-tick order is
`MatchTick.Advance` (F-06e).

## Create

**`Runtime/SimSpace.cs`** (namespace `CriticalMass.Runtime`, O-13 ruling): the only place in the project that converts
between Sim axes and Unity axes. No other file negates a z (no `-simZ`, no `-hit.z` anywhere else).

```csharp
public static class SimSpace
{
    public static Vector3 ToWorld(double simX, double height, double simZ) => new Vector3((float)simX, (float)height, (float)-simZ);
    public static void ToSim(Vector3 world, out double simX, out double simZ) { simX = world.x; simZ = -(double)world.z; }
    public static float YawDeg(double facing) => (float)(90.0 + facing * 180.0 / Math.PI);   // sim facing 0 = +X
    public static Quaternion CameraRotation(GameConfig c) => Quaternion.Euler((float)c.Render.CameraPitchDeg, (float)(360 - c.Render.CameraYawDeg), 0f);
}
```

`YawDeg`: sim facing `f` points along sim `(cos f, sin f)` (movement.ts `atan2(dz, dx)`), which is Unity
`(cos f, 0, -sin f)`; `Quaternion.Euler(0, 90 + f_deg, 0) * Vector3.forward` is exactly that.

**`Runtime/Input/HumanInputSource.cs`** (namespace `CriticalMass.Runtime.Input`; moved here from F-07 because it needs
`SimSpace`): `public sealed class HumanInputSource : MonoBehaviour` with `public HumanInputState State { get; } = new HumanInputState();`.
`OnEnable`: `var map = InputSystem.actions.FindActionMap("Player", true); map.Enable();` and subscribe `started` /
`canceled` of `Jump`, `Attack`, `Ability`, `Interact`, `DigPlace`, `Pause`, `Scoreboard` to `State.ButtonDown(b)` /
`State.ButtonUp(b)` (`InputAction.started` fires once per press; key repeat raises no new `started`).
`Update`: `var m = map["Move"].ReadValue<Vector2>(); State.SetMove(m.x, m.y);` aim: when `Mouse.current == null` ->
`State.ClearAim()`; else `ray = Camera.main.ScreenPointToRay(map["Point"].ReadValue<Vector2>())`, intersect with
`new Plane(Vector3.up, 0)`; on a hit `SimSpace.ToSim(ray.GetPoint(d), out sx, out sz); State.SetAim(sx, sz);`, no hit ->
`State.ClearAim()`. `OnApplicationFocus(bool f)`: `if (!f) State.Blur();`. `OnDisable` unsubscribes.


**`Runtime/Game/GameBootstrap.cs`**: `public static class GameBootstrap`. `[RuntimeInitializeOnLoadMethod(RuntimeInitializeLoadType.AfterSceneLoad)] static void Install()`
subscribes `SceneManager.sceneLoaded` and calls `Build` for the active scene. `public static GameObject Build(Scene scene)`:
when `scene.path == "Assets/_Game/Scenes/Boot.unity"` and no `SimDriverBehaviour` exists, creates in that scene a root
`Game` GameObject holding, in this order: `SimDriverBehaviour`, `HumanInputSource` (F-07), `ActorViews`,
`GridChunkMeshView` (F-08b), `DebugHud` (F-08c); a `Main Camera` (tag `MainCamera`, `Camera` + `CinemachineBrain`,
background `Palette.VoidNavy`, `clearFlags = SolidColor`); the camera rig of F-08b (`CameraRig.Create(driver)`); one
`Directional Light` (rotation Euler(50, 330, 0), intensity 1, colour white, soft shadows). Returns the `Game` object.
No scene file is edited (Boot.unity stays empty; O-17, U-027). `Install` first does `SceneManager.sceneLoaded -= OnSceneLoaded;`
then `+=` (the project disables domain reload on entering Play Mode, `ProjectSetup.ApplyEditorSettings`, so statics and
subscriptions survive between play sessions).

**`Runtime/Game/SimDriverBehaviour.cs`**: `public sealed class SimDriverBehaviour : MonoBehaviour`:

| Member | Meaning |
| --- | --- |
| `public World World { get; private set; }` | created in `Awake`: `World.CreateWorld(new WorldOptions { Seed = cfg.Seed, TeamSize = cfg.TeamSize, HumanTeam = TeamId.Azure, HumanClass = ClassId.Warrior, Config = cfg })`, `cfg = GameConfig.CreateDefault()` |
| `public GameConfig Config { get; private set; }` | `cfg` |
| `public double TimeScale = 2;` | set from `cfg.DefaultSpeed` in `Awake` |
| `public bool HumanAutopilot;` | `true`: actor 0 bot-driven (`MatchTick.Advance(w, null, scratch)`) |
| `public double Alpha { get; private set; }` | interpolation fraction |
| `public double FrameDt { get; private set; }` | `Math.Min(Time.unscaledDeltaTime, 0.1)`, for the camera |
| `public void StepTicks(int n)` | runs `n` ticks immediately (smoke test) |

`Update`: `FrameDt = min(unscaledDeltaTime, 0.1)`; `if (!input.State.Paused) acc += Math.Min(Time.unscaledDeltaTime, 0.25) * TimeScale;`
`while (acc >= dt) { input.State.Fill(humanFrame); MatchTick.Advance(World, HumanAutopilot ? null : humanFrame, scratch); acc -= dt; }`;
`Alpha = acc / dt`. `dt = SimStep.Dt(cfg)`. Match end: the driver keeps ticking (`Step` is inert).

**`Runtime/View/PlaceholderMaterials.cs`**: `public static class PlaceholderMaterials { public static Material Get(string hex); }`:
`baseMat = Resources.Load<Material>("Placeholder/PlaceholderLit")` (created by F-07's `ProjectSetup.ApplyPlaceholderMaterial`;
null -> `throw new InvalidOperationException("run ProjectSetup.Apply")`), then caches `new Material(baseMat)` per hex with
`SetColor("_BaseColor", c)`, `c` from `ColorUtility.TryParseHtmlString(hex, out c)`. Never `Shader.Find`; never
`GraphicsSettings.currentRenderPipeline.defaultMaterial` at runtime (it is null in a player build).

**`Runtime/View/ActorViews.cs`**: `public sealed class ActorViews : MonoBehaviour`. Creates once (`Start`):
`ActorCapacity` capsules (`GameObject.CreatePrimitive(PrimitiveType.Capsule)`, collider destroyed), one kaiju cube,
one cube per resource node, one flat cube for the hill. `LateUpdate` per actor `i < ActorCount`: active when
`Alive`; position `SimSpace.ToWorld(lerp(PrevX, X, a), h + CharacterHeight / 2, lerp(PrevZ, Z, a))` with `h = Map.Height01[cell]`;
scale `(2r, CharacterHeight / 2, 2r)`, `r = Class(Cls).Radius`; yaw `Quaternion.Euler(0, SimSpace.YawDeg(Facing), 0)` (sim facing 0 =
+X); material `Palette.Azure` / `Palette.Crimson`, actor 0 scaled 1.15 in X and Z. Kaiju:
shown in every state; scale `(2 * Kaiju.Radius, KaijuHeight, 2 * Kaiju.Radius)`; material by state Egg `Cream`, Neutral
`Stone`, Azure `Azure`, Crimson `Crimson`, Berserk `Corruption`. Nodes: cube 0.6, `Biomass` / `Corruption`, scale Y
`0.3 + 0.1 * Charges`. Hill: cube `(2R, 0.05, 2R)` at the hill centre, `Brass`. Barricades are grid cells (F-08b).

`Hill.Radius` 6; accumulator caps 0.25 s, frame dt cap 0.1 s; actor-0 scale 1.15; light Euler(50, 330, 0).

## Behaviour notes

- Axes: every Sim-to-Unity position goes through `SimSpace` (O-13 ruling). Facing: sim `Facing` is the browser's angle; `SimSpace.YawDeg` is
  derived in its own section above. Kaiju, node and hill cubes use `SimSpace.ToWorld` the same way.
- Every new file and folder gets its `.meta` from Unity on import (U-027): write none.
- No Unity physics: primitives lose their colliders on creation.

## Play check (described; the integrator runs it on the Mac build)

Launch the build: within 2 s a grey-box basin is visible from the 45°/38° camera, 32 capsules (16 cyan, 16 coral) move
at 2x, the human capsule (larger) follows WASD relative to the screen (W = up the screen), right mouse casts the shield
(event in the HUD log), Esc pauses (HUD shows PAUSED, nothing moves), at 4:00 on the HUD clock (2:00 wall time) the
kaiju cube changes colour, the match ends at 8:00 with a winner line in the HUD.
