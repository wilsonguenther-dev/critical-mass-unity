## Create

**`Assets/_Game/Sim.Tests/GameConfigGoldenTests.cs`** (namespace `CriticalMass.Sim.Tests`, `public sealed class
GameConfigGoldenTests`, **new, no vitest twin**). Read `tools/golden/game-config-09e0904.json` with `File.ReadAllText`
from the project root. The leaves are the members of the `"leaves"` object; parse each with
`"([^"]+)":\s*(true|false|"[^"]*"|-?[0-9][0-9.eE+-]*)` on the text after `"leaves":`. Numbers parse with
`double.Parse(s, NumberStyles.Float, CultureInfo.InvariantCulture)` (JSON keeps the shortest round-trip form, so the
parse is exact).

Resolver `static bool TryResolve(GameConfig c, string path, out object value, out string why)`:

1. Split the path into segments on `.` and on `[i]` (an index segment).
2. Start at the `GameConfig` instance. For a name segment, PascalCase it (first letter upper, rest unchanged:
   `thinkHz` -> `ThinkHz`) and read the public field, then the public property, of that exact name by reflection.
3. A name segment equal to a class id (`warrior`, `farmer`, `miner`, `demolitions`, `builder`) applied to an `IList`
   indexes it by `(int)ClassId.<Pascal>`; a team id (`azure`, `crimson`) applied to a `PerTeam` reads its indexer
   with `TeamId.<Pascal>`.
4. An index segment applied to an `IList` reads element `i`.
5. Before step 2, the path is rewritten by `Renames`, a `static readonly (string ts, string cs)[]` of whole-prefix
   rewrites, for every leaf whose C# name in F-01's Numbers table differs from the PascalCase rule. Fill it from
   F-01's table (`loop/items/F-01.md`, the C# column against the browser column), one entry per difference, with the
   F-01 table row as a trailing comment.
6. `NotPorted`: a `static readonly string[]` of golden paths F-01 states are not ported to `GameConfig`, each with the
   F-01 line that says so as a trailing comment. A leaf the resolver cannot reach that F-01 does not exclude is a red
   (an F-01 gap): the builder writes it as an open question with the list, and does not add it to `NotPorted`.

**`Assets/_Game/Sim.Tests/SharedScratchTests.cs`** (batch-1 review finding R20261112T1705-1-5, U-047; `public sealed class
SharedScratchTests`, **new**). `FlowField` (`Heap`, `HeapPos`, `HeapKey`, `Closed`, `HeapSize`) and `World` (`RosterCounts`,
`RosterFrac`, `RosterScratch`) keep process-wide static scratch, as the browser keeps module scope. The ruling keeps the
scratch and proves it carries nothing between calls:

  goal set H = the hill centre cell, goal set P = the Azure pad centre cell. Alone: `ComputeFlowField(map, H)` then, in

  Assert every alternate `Dist` equals its alone copy bit for bit (`BitConverter.DoubleToInt64Bits`).
- `TwoWorldsCreatedAndResetAlternatelyEqualEachAlone`: worlds A (`Seed` 1, `TeamSize` 5) and B (`Seed` 2, `TeamSize` 16),

  snapshot `X`, `Z`, `Facing`, `Cls`, `Team` of every actor and `Rng.State`; same for B. Alternate: create A, create B,
  reset A, reset B, reset A, reset B. Assert both final snapshots equal the alone ones bit for bit.
