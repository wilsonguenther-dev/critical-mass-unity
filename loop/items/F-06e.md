## Behaviour notes

- Quotas (director.ts lines 175-176), exactly: `hillQuota = (int)Math.Ceiling(count * B.HillMinFraction)`,
  `kaijuQuota = Math.Max(1, (int)JsMath.Round(count * B.KaijuGroupFraction))` (16 * 0.25 = 4; 5 * 0.25 = 1.25 -> 1). The
  products are `double * double` as in JS, so `Math.Ceiling` sees the same binary value (for example 10 * 0.3 =
  3.0000000000000004 -> 4 in both runtimes); keep them `double` products (no `int`, no `decimal`).
- `BotsThink`: `if (w.Match.Phase == MatchPhase.Ended) return;` comes after `GetBotsState`; a bot thinks when
  `(tick + id) % period == 0 || a.AiState == AiState.None` (operands non-negative, so C# `%` equals JS `%`); actor 0 is
  handled by `bool human = HumanDriven(st, w); ... if (id == 0 && !human) continue;`, exactly index.ts lines 46-66.
- `BotsThink` staggers bot thinking over `ThinkPeriod` ticks with the browser's own expression, ported as written.
