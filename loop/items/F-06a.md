## Numbers

`Seed`, `SimHz` 30, `Bots.ThinkHz` 4: `ThinkPeriod = Math.Max(1, (int)JsMath.Round((double)SimHz / Bots.ThinkHz))` = 8.
Personality draws: `Aggression`, `Greed` from `Rng.NextFloat` in 0.8..1.2 as written.

## Behaviour notes

- Bot RNG: the state is created once and re-seeded in `ResetBotsState` with `Rng.SeedRng(st.Rng, unchecked((uint)(w.Opts.Seed + BotSeedOffset)))`
  (browser `seedRng(st.rng, (seed + 7919) >>> 0)`, state.ts line 116).
- `Aggression`, `Greed`, `Anchor*`, `Progress*`, `Unstick*`, `Post*`, `Ability*` are `Float32Array` in the browser and
  `double[]` here (O-01): a personality draw keeps all 53 bits instead of 24. Decisions that compare them can in rare
  seeds differ from the browser; the per-case bot tests assert bands, so this is accepted (U-002).
- `headingDelta` wraps with `Math.round(d / (2 * Math.PI))`: `JsMath.Round`.
- The baseline test reads `heading-before.json` (`{ seed: 1, teamSize: 5, ticks: 300, perBot: number[] }`) with
  `System.IO.File.ReadAllText("Assets/_Game/Sim.Tests/Data/heading-before.json")` and a 10-line hand parser for this
  fixed shape (no JSON package in Sim.Tests: `perBot` is the only array).
- The heading test helper (displacement velocity, sampled when speed >= `HeadingMinSpeedFraction * moveSpeed`) is
  ported into the fixture.
