## Numbers

`SimHz` 30, `MatchSeconds` 480, `HatchSeconds` 240, `DrawEpsilonSeconds` 0.1, `Hill.Radius` 6.

## Behaviour notes

- Hill membership: `dx*dx + dz*dz < R*R` strictly (the test puts one actor exactly at R, outside).
- `HillOwnerChange` event value codes 0, 1, 2, 3 = Neutral, Azure, Crimson, Contested (the enum order).
- `MatchSystem` ends the match when `m.Time + dt >= MatchSeconds` (match.ts line 17; `Time` is advanced after it in
  `Step`), then `Winner = DecideWinner(HillSeconds.Azure, HillSeconds.Crimson, DrawEpsilonSeconds)` and one `MatchEnd`
  event (a 0, b 0, at the hill centre, value = azure - crimson hill seconds). `DecideWinner`: `Math.Abs(azure - crimson) <= eps`
  -> `Draw`, else the larger. `GetMatchClock`: `Remaining = Math.Max(0, MatchSeconds - t)`, `UntilHatch = Math.Max(0, HatchSeconds - t)`.
- Hill seconds accumulate `dt` per step: after `n` steps the test expects `n * dt` within 1e-9.
