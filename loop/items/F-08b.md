## Create

**`Runtime/Camera/CameraSpring.cs`** (pure C#): `public sealed class Spring1 { public double X; public double V; }` and
`public static class CameraSpring { public const double FollowOmega = 9; public const double LookAheadSeconds = 0.25; public const double LookAheadMax = 2.0; public const double LookAheadTau = 0.1; public const double TeleportSpeed = 20; public static Spring1 CreateSpring(double x); public static void SpringStep(Spring1 s, double target, double omega, double dt); public static int SpringSettleTicks(double d, double eps, double omega, double hz); }`.
`SpringStep` exactly: `if (!(dt > 0)) return; double y = s.X - target; double n = s.V + omega * y; double e = Math.Exp(-omega * dt); s.X = target + (y + n * dt) * e; s.V = (s.V - n * omega * dt) * e;`.

**`Runtime/Camera/CameraFollowTarget.cs`**: `public sealed class CameraFollowTarget : MonoBehaviour` with
`public SimDriverBehaviour Driver;`. `LateUpdate`, with `dt = Driver.FrameDt` and actor 0's interpolated sim position
`(px, pz)` and velocity `(Vx[0], Vz[0])`, all in sim axes: look-ahead target `la = v * LookAheadSeconds`, length capped at `LookAheadMax`;
eased `ease += (la - ease) * (1 - Math.Exp(-dt / LookAheadTau))`; goal `= p + ease`, clamped to
`[Bounds.MinX + inset, Bounds.MaxX - inset] x [Bounds.MinZ + inset, Bounds.MaxZ - inset]`, `inset = Render.CameraBoundsInset`;
if the goal moved faster than `TeleportSpeed` u/s since the last frame: `X = goal, V = 0` on both springs; else
`SpringStep(sx, goalX, FollowOmega, dt)` and the same for z. `transform.position = SimSpace.ToWorld(sx.X, 0, sz.X)` (F-08a; no file here negates z).

**`Runtime/Camera/CameraRig.cs`**: `public static class CameraRig { public static GameObject Create(SimDriverBehaviour driver); }`:
creates `CameraTarget` (with `CameraFollowTarget`) and `CM Camera` with `Unity.Cinemachine.CinemachineCamera`
(`Follow = CameraTarget`, `Lens.ModeOverride = LensSettings.OverrideModes.Orthographic`, `Lens.OrthographicSize = (float)(Render.ViewHeightUnits / 2)` = 10 (explicit cast: the config value is `double`),
near clip 0.1, far clip 200) and `CinemachineFollow` (`using Unity.Cinemachine.TargetTracking;` for `BindingMode`, which lives in that namespace in Cinemachine 3.1.7
`Runtime/Core/TargetTracking.cs`; `TrackerSettings.BindingMode = BindingMode.WorldSpace`,
`TrackerSettings.PositionDamping = Vector3.zero`, `FollowOffset = -(SimSpace.CameraRotation(cfg) * Vector3.forward) * (float)Render.CameraDistance`). `Lens` and
`TrackerSettings` are public struct fields (`CinemachineCamera.Lens`, `CinemachineFollow.TrackerSettings`), so member
assignment such as `cam.Lens.OrthographicSize = 10f;` writes the component's own value; near and far clip are
`Lens.NearClipPlane` and `Lens.FarClipPlane`.
The camera rotation is fixed: `CM Camera` transform rotation `SimSpace.CameraRotation(cfg)` = Euler (38, 315, 0); the
`CinemachineCamera` gets no rotation-control component, so the brain keeps that rotation.

**`Runtime/View/GridChunkMeshView.cs`**: `public sealed class GridChunkMeshView : MonoBehaviour`, `public const int ChunkSize = 16;`.
On `Start`: one child GameObject per 16 x 16 chunk (112 x 72 map: 7 x 5 chunks), each with `MeshFilter`, `MeshRenderer`
and one submesh per cell look below. A cell is drawn as a box from `y = bottom` to `y = top`:

| Cell | top | bottom | Palette |
| --- | --- | --- | --- |
| `Floor`, `BreakableDestroyed` | `Height01` | `Height01 - 0.5` | `Cream` |
| `Bridge` | `Height01` | `Height01 - 0.2` | `Brass` |
| `Wall` | `Height01 + 1.5` | `Height01 - 0.5` | `Stone` |
| `BreakableIntact` | `Height01 + 1.5` | `Height01 - 0.5` | `Brass` |
| `BreakableCracked` | `Height01 + 0.75` | `Height01 - 0.5` | `Brass` |
| `Barricade` | `Height01 + 1.0` | `Height01 - 0.5` | `Meat` |
| `Water` | `-0.2` | `-0.4` | `SkyTop` |
| `Void` | not drawn | - | - |

Cell `(cx, cz)` spans sim `[cx, cx+1] x [cz, cz+1]`; vertices go through `SimSpace.ToWorld`, and each face's
triangle winding is chosen after the conversion so normals point outward (the z flip mirrors handedness). `LateUpdate`: when `World.GridVersion` differs from the
last seen value, compare `Map.Cells` with a kept copy and rebuild only chunks with a changed cell. Materials from
`PlaceholderMaterials.Get` (F-08a).
