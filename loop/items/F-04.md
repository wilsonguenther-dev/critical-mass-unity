## Behaviour notes

- `(p - 1) >> 1` (heap parent) and `c % W` (cell to column) have non-negative operands: C# `>>` and `%` match JS.
- Heap order: the browser heap breaks ties by insertion order of its array implementation; port the heap line for line
  (same sift-up/sift-down comparisons, `<` versus `<=` exactly as written) so equal-cost cells pop in the same order.
- `dist` is a `Float32Array` in the browser; here `double[]`. Unreachable = `double.PositiveInfinity`.
- The route test asserts RANGES, not decimals (map.test.ts lines 110-124, title "44..76 cells ... 28..52"): for both pads
  `44 <= dPadHill <= 76` and `28 <= dPadShrine + dShrineHill - dPadHill <= 52`, with `Assert.GreaterOrEqual` /
  `Assert.LessOrEqual` and no tolerance.
- The kaiju-lane test uses `MapGrid.ClearanceOk(map, cx, cz, config.Kaiju.GridRadius)` and an 8-connected flood fill,
  ported from the test's helper.
