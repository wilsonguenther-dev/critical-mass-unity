**`Core/JsMath.cs`**: `public static class JsMath { public static double Round(double v); public static int FloorToInt(double v); public static double F32(double v); }`
(conventions 6.1, 6.2 and 6.3).

- `Round` (panel revision 2026-11-12, P-04): `double f = Math.Floor(v); return (v - f >= 0.5) ? f + 1 : f;` (NaN and
  infinities pass through). Do NOT write `Math.Floor(v + 0.5)`: it differs from JS `Math.round` at 0.49999999999999994
  (JS 0, floor form 1) and at odd integers from 2^52 up (the `+ 0.5` rounds up before the floor).
- `F32` (panel revision 2026-11-12, P-03): `return (double)(float)v;`. This is JS `Math.fround` exactly (an explicit C#
  `float` cast rounds to nearest-even, `conv.r4`). Every store into a field the browser holds in a `Float32Array`, and
  every `Math.fround(v)`, is written `JsMath.F32(v)` (conventions 6.1).
- **new, no vitest twin**: `JsMathTests.RoundMatchesJsMathRoundAtTheEdgesAndF32MatchesMathFround`, one method with these
  `Assert.AreEqual` rows (values from node 22 on this Mac): `Round(0.49999999999999994) == 0`, `Round(0.5) == 1`,
  `Round(-0.5) == 0`, `Round(2.5) == 3`, `Round(-2.5) == -2`, `Round(4503599627370497.0) == 4503599627370497.0`;
  `F32(0.1) == 0.10000000149011612`, `F32(1.0000001) == 1.0000001192092896`, `F32(16777217.0) == 16777216.0`,
  `double.IsPositiveInfinity(F32(1e39))`, `double.IsNaN(F32(double.NaN))`.

## Behaviour notes

- `NextFloat`, exactly: `unchecked { r.State += 0x6D2B79F5u; uint t = r.State; t = (t ^ (t >> 15)) * (t | 1u);
  t ^= t + (t ^ (t >> 7)) * (t | 61u); return (t ^ (t >> 14)) / 4294967296.0; }`. `Math.imul` keeps the low 32 bits,
  the JS `t + imul(...)` sum is truncated to 32 bits by `^=`, and `>>> 0` reinterprets as unsigned: `uint` arithmetic
  reproduces all three.
- `NextInt`: `span <= 0` returns `minIncl`; else `minIncl + JsMath.FloorToInt(NextFloat(r) * span)`.
- The "plain serialisable number" test: copy `State` into a new `Rng` and compare the next draws.
- Boundary port: scan every `*.cs` under `Assets/_Game/Sim/` (recursive, path from the project root, which is the
  EditMode working directory), strip `//` and `/* */` comments, and flag: `using UnityEngine`, `using UnityEditor`,
  `UnityEngine.`, `System.Random`, `DateTime.Now`, `DateTime.UtcNow`, `Stopwatch`, `Environment.TickCount`,
  `Guid.NewGuid`, `System.Threading`. Also assert `Assets/_Game/Sim/CriticalMass.Sim.asmdef` contains
  `"noEngineReferences": true`. "Real set" = at least 12 files (the browser threshold). "Guard catches a violation":
  run the same checker on the in-memory string `"var r = new System.Random();"` and assert one violation.
