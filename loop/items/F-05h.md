## Behaviour notes

- `MaxHp = Kaiju.HpPerTeamMember * TeamSize` (the test asserts both 5v5 and 16v16 through `GameConfig.CreateBrowser5v5()`
  with `TeamSize` 5 and 16 passed in `WorldOptions`).
- The melee wind-up is counted in whole ticks: `Kaiju.MeleeWindupIn` is an `int` (canonical listing) set to
  `(int)cfg.Kaiju.MeleeWindupTicks` (11; the config field is `double`) and decremented by 1 per step (kaiju.ts lines 489-491);
  `MeleeWindupTicks / SimHz` = 0.3667 s.
- `nearestClearCell` searches rings outward in the browser order (`for r = 0..maxRings`, then the ring's cells in the
  written loop order); the first clear cell wins, so the loop order is part of the oracle: port it as written.
- The forced-hatch test compares two worlds field by field (`State`, `Hp`, `MaxHp`, `X`, `Z`, allegiance, events).
- No CM-85 code exists in `kaiju.ts` (checked on 09e0904), so nothing is cut here.
