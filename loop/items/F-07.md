Rules (from `humanInput.ts`): `Jump`, `Ability`, `DigPlace` (-> `InputFrame.Terraform`) and `Attack` are edge-latched:
a down sets a latch, `repeat` downs are ignored, `Fill` copies and clears each latch; `Attack` is also true on every
`Fill` while held. `Interact` is held. `Pause` down toggles `Paused`; while paused `Fill` writes `SimInput.EmptyInput()`
values with `AimX = AimZ = double.NaN`, and every down except `Pause` is dropped (never replayed). `Blur` clears every
held button, the move vector and every latch. Move: `(right * ScreenRightX + up * ScreenUpX, right * ScreenRightZ + up * ScreenUpZ)`,
scaled to length 1 when longer. No aim: `AimX = AimZ = double.NaN`. `ClassPick` = the queued class once, then -1.
