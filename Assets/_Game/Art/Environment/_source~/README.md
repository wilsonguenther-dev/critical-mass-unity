# Skybreak Basin environment kit (floating ruins), v1

A modular kit that tiles on the game's cell grid (F-03), not a fused level mesh. Everything here is generated by
script in headless Blender 5.2.3; the `.blend` and the FBX files are build outputs.

## Rebuild

From the repo root (exit 0 from clean; about 10 s each):

```
B=/Applications/Blender.app/Contents/MacOS/Blender
D="Assets/_Game/Art/Environment/_source~"
$B -b --factory-startup --python-exit-code 1 --python "$D/build_env_kit.py"                 # env_kit.blend, ../env_*.fbx, manifest
$B -b --factory-startup --python-exit-code 1 --python "$D/verify_and_render.py" -- <out_dir> # FBX re-import, tiling checks, renders
python3 "$D/compose_sheets.py" <out_dir>/renders <out_dir>/sheets                            # sky, bible side-by-sides, contact sheet
```

`verify_and_render.py ... --no-render` runs the checks only. `--only <framing>` renders one framing.

| File | What |
| --- | --- |
| `build_env_kit.py` | builds every piece, exports one FBX per piece to `Assets/_Game/Art/Environment/`, writes `env_kit.blend`, `manifest.json`, `MANIFEST.md` |
| `env_art/pieces.py` | the pieces (authored in Unity axes) and the registry: size in cells, pivot, bible element, cull mode, outline width |
| `env_art/geo.py` | mesh builder: Unity-space authoring, camera-facing face culling, Blender axis conversion |
| `env_art/layout.py` | 1:1 Python port of `src/sim/map.ts` at 09e0904 (the F-03 source) plus the view-side placement rules |
| `env_art/palette.py` | environment palette sampled from the bible (provenance per entry). **To be merged into the shared palette module `cm_art/palette.py` on branch `art/warrior-blender`** (same mask codes and `lin()` convention; adds code 0.25 = fixed-colour self-lit) |
| `env_art/toon.py` | Blender preview of the CM/Toon contract (two-band ramp, emission, inverted hull), mirrors `cm_art/toon.py` |
| `verify_and_render.py`, `compose_sheets.py` | checks and look-dev renders |

Export recipe (same as `cm_art/export.py`): FBX, `apply_scale_options=FBX_SCALE_ALL`, `axis_forward=-Z`, `axis_up=Y`,
`bake_space_transform=True`, per-face smoothing, sRGB vertex colours (one colour set named `Col`; RGB = bible hex,
ALPHA = mask code), no textures, no materials that matter (CM/Toon reads the vertex colour). 1 unit = 1 m = 1 cell.
Blender to Unity: `unity = (-bx, bz, -by)`. Unity `.meta` files are not committed (Unity was not run).

## How the Unity side places pieces from the cell grid

All positions go through `SimSpace.ToWorld(simX, height, simZ) = (simX, height, -simZ)`.

1. **Ground, per cell** (so dig, place and breakable edits swap one piece). For every cell `(cx, cz)` place at
   `ToWorld(cx + 0.5, Height01, cz + 0.5)`, rotation identity:
   `Floor` -> a ground variant (`env_ground_grass_a/b/c`, `path_a/b/c`, `mossy`, `dirt`, `corrupt`; rule in
   `layout.ground_variant`), `Wall` -> `env_wall` (shrine solid cells -> `env_ground_path_a`, the dais covers them),
   `BreakableIntact/Cracked/Destroyed` -> `env_wall_breakable_intact/cracked/destroyed`, a Miner-placed cell ->
   `env_ground_placed`, `Bridge` -> nothing if a span covers the whole cell, else `env_bridge_cell` at `Height01 - 0.06`
   (`layout._cell_under_span`). Ground pieces have a 0.75 m side skirt (one height step) on their east and south faces;
   stack `env_ground_fill` under a cell for each extra step.
2. **Cliffs.** A ground cell whose east (+x), south (+z) or south-east neighbour is not ground at the same or a
   greater height (void, bridge, out of map, lower ground) gets `env_cliff_a/b/c` (hash pick) at the same position
   (`layout.is_edge`). Re-run it for the neighbours of a dug cell, so a hole shows rock walls.
3. **Never rotate `cull = cam` pieces** (see `MANIFEST.md`): faces the fixed camera (pitch 38, yaw 45) cannot see are
   not in the mesh. `cull = down` pieces (bridge span, fallen columns, waterfall) may be yawed.
4. **Bridges.** For each `SkybreakBasinMap.Bridges` row (and its mirror), take the t-range where the segment passes
   over `Bridge` cells, extend 0.6 m onto each island, tile `env_bridge_span` (1 m along local +Z, 3 m wide) with
   `n = round(length)` tiles stretched to the exact length, yawed to the heading and pitched by the endpoint-island
   height lerp (heights from the UNMIRRORED endpoints, as map.ts paints them). `env_bridge_post` at both ends, both
   sides (`layout.all_spans`, `span_placements`). The diagonal bridges are the same spans at their heading; the
   stair-step cells along their sides get `env_bridge_cell` so every walkable cell reads as walkable.
5. **Objectives.** `env_hill_plaza` at `ToWorld(56, 0.75, 40)`; two `env_hill_rim_half` there at yaw 90 (west, Azure)
   and 270 (east, Crimson); the rim is team-glow masked so the game colours each half (neutral, owner, split).
   `env_spawn_pad` at each pad centre (8, 36) / (104, 36), `env_banner` and `env_crystal_cluster*` around it with the
   team set by the CM/Toon team value. `env_shrine_dais`, `env_shrine_horns` and `env_shrine_egg_proxy` at
   `ToWorld(56, 1.5, 8)`.
6. **CM-31 pillars.** `env_ruin_column_intact` on each `Decorations` base cell. When toppled, swap to
   `env_ruin_column_fallen_ramp` (fall along `Ramp`) or `env_ruin_column_fallen_block` (fall along `Block`) at the same
   pivot, Unity yaw `0` for sim (0, -1) north, `90` for (1, 0) east, `180` for (0, 1) south, `270` for (-1, 0) west.
   Footprint: base cell plus `topple.lengthCells` (4) along the fall, `widthCells` (3) wide.
7. **Decoration and sky** (no Sim meaning): trees, bushes, rocks, ruin blocks and stubs, edge stones, crystals on the
   team halves, waterfalls off south and east edges, sky rocks around the map, cloud puffs and `env_cloud_floor`
   below (`layout.place`, deterministic `h32` hash, portable to C# as unchecked uint arithmetic). Decoration stays off
   the hill, pads and shrine keep-outs, and anything on a walkable cell is under bush height except edge trees.
8. **Batching.** Combine each 16 x 16 chunk's cell pieces into one mesh per material (F-08b's chunk size) and rebuild
   a chunk when its cells change, as F-08b already does for its boxes.
9. **Outline width per piece** is in `manifest.json` (`outline_m`): none on ground cells (a hull per flagstone draws a
   dark grid over the paving), 0.03 cliffs, 0.04 bridges and edge stones, 0.06 props.

## Checks (`verify_and_render.py`)

FBX re-import of every piece (triangle count, Unity-axis bounds within 2 mm, colour set present); the Skybreak Basin
test scene assembled from the F-03 grid; 5 down-rays per walkable cell (4 corners inset 0.02 m and the centre) must
hit kit geometry within 0.12 m of `Height01` (0.2 m on bridges); every ground piece's footprint equals its cell within
1e-4; every edge cell has a cliff; ground stays inside [0, 112] x [0, 72]. Results: `<out_dir>/checks.json`.
