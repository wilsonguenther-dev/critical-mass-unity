# Critical Mass props set v2 (bible p14 + p03 strip + neutral dressing)

v2 report and numbers: `~/Obsidian/Wilson-Brain/Projects/Kaiju-Demo/unity-port/props-v2/REPORT.md`.

Everything is generated by script in headless Blender 5.2.3; `props.blend`, `manifest.json` and `../prop_*.fbx` are
build outputs. No hand edits.

## Rebuild (from the repo root)

```
B=/Applications/Blender.app/Contents/MacOS/Blender
D="Assets/_Game/Art/Props/_source~"
OUT=~/Obsidian/Wilson-Brain/Projects/Kaiju-Demo/unity-port/props-v2
$B -b --factory-startup --python-exit-code 1 --python "$D/build_props.py"            # 32 FBX, props.blend, manifest.json
$B -b --factory-startup --python-exit-code 1 --python "$D/verify_fbx.py"             # re-import every FBX
for s in lineup district field ortho; do
  $B -b --factory-startup --python-exit-code 1 --python "$D/render_props.py" -- "$OUT" --only $s
done
python3 "$D/compose_sheets.py" "$OUT"                                                # sheets, sbs, checks.json
```

The lineup fetches the Warrior silhouette from `origin/art/warrior-blender` through `git lfs smudge` into `_out/`.
The district and field shots import the environment kit FBX from `Assets/_Game/Art/Environment/` (read only).

| File | What |
| --- | --- |
| `props_art/core.py` | palette, bmesh primitives (bevelled box, cylinder, tube, torus, cloth), `Prop` builder (one mesh, `Col` colour set, vertex gradient, `lined` group), CM/Toon three-band preview material, FBX export recipe (same as `cm_art/export.py`) |
| `props_art/props.py` | one builder per prop and the `REGISTRY` (name, builder, bible element) |
| `props_art/bible.py` | bible crop foreground mask (shared by the renderer and the checks) |
| `build_props.py` | builds, checks size and triangle budgets, exports, writes the manifest |
| `render_props.py` | gameplay-camera lineup / district / field, orthographic bible framings fitted to each crop |
| `compose_sheets.py` | labelled sheets, side by sides, IoU and dE2000 checks (`checks.json`) |

## Contract for the Unity side

* 1 unit = 1 m; pivot = footprint centre on the ground; front = Unity +Z. Static meshes, one material (CM_Toon).
* Vertex colour set `Col`: RGB = bible hex, A = mask code. 0 fixed (shaded), 0.125 fixed self-lit glow WITH outline
  (v2: biomass plants, orbs, glassy highlights), 0.25 fixed self-lit glow, unlined (corruption seams, flame, neutral
  marker), 0.375 marker light (team, self-lit, unlined; azure #27F8F8, crimson #E6A595), 0.5 team dark, 0.625 team
  glow WITH outline (v2: crystals, lamp), 0.75 team glow, unlined, 0.875 marker dark (team, self-lit, unlined; azure
  #43C2C5, crimson #D6594F), 1.0 team cloth. Codes are 0.125 apart: compare with a tolerance under 0.06. Team props
  (`prop_banner`, `prop_marker_team`, `prop_crystal_*`, `prop_crystal_lamp`, barricade cloth) are authored Azure;
  the CM_Toon team value swaps them to Crimson.
* Outline: 2.5 px Void Navy #18233B, constant screen width. The hull width must be multiplied by 0 where A is 0.25,
  0.375, 0.75 or 0.875 (unlined glows and markers); 0.125 and 0.625 glows keep the hull (the bible inks them).
  `outline_px` per prop is in `manifest.json` (0 = no hull: markers).
* Three bands (1.00 / 0.84 / 0.66 + 12% Void Navy) at N.L 0.35 / -0.05; vertex gradient +6% top / -10% bottom is
  already baked into `Col`.
* Lights are not in the FBX: `prop_brazier` wants a #FFC27A point light r 2.0 u + 2.0 u pool decal at 35%;
  `prop_crystal_lamp` a team-colour point light r 1.5 u at 60%. The renders show the pools as preview discs.
* Damage states are separate meshes: `prop_barricade_folded / deployed / damaged`.
* Walkable-cell dressing (under 0.3 u): `prop_pebbles`, `prop_planks`, `prop_rope_coil`, `prop_biomass_sprout`.
